# Topological Physics from Scratch

**A computational physics learning and research project using Python.**

This repository documents my journey into numerical quantum mechanics, Berry phase, Berry curvature, and topological invariants. I aim to implement the mathematics from scratch, test numerical results, and develop reproducible computational workflows.

## Research Interests

- Numerical quantum mechanics and wavefunctions
- Hamiltonian eigenvalues and eigenstates
- Berry phase and Berry curvature
- Chern numbers and topological band theory
- Machine learning for topological materials
- Computational materials science, density functional theory (DFT), and cluster expansion

## Tools and Technologies

- Python
- NumPy and SciPy
- Matplotlib
- Jupyter Notebook
- Git and GitHub
- Linux

## Project Roadmap

- [ ] Build numerical quantum mechanics utilities
- [ ] Calculate Berry phase around a closed parameter loop
- [ ] Implement Berry curvature and Chern-number calculations
- [ ] Validate results against analytical benchmarks
- [ ] Explore machine learning for topological phase classification
- [ ] Progress toward cluster expansion and DFT workflows

## Research Philosophy

I want to understand the mathematics behind each method, write and debug my own implementations, validate results against known physics, and document both successes and failures.

*This repository is a work in progress. The roadmap will be updated as each project is implemented and tested.*
